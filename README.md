# Counter-Strike Statistics Analysis

## Sobre o projeto

Este projeto está a ser desenvolvido no âmbito do Trabalho Final de Curso (TFC) da Licenciatura em Ciência de Dados da Universidade Lusófona.

O objetivo é explorar e analisar dados estatísticos do Counter-Strike, procurar identificar padrões e relações entre diferentes indicadores de desempenho de jogadores e equipas.

## Fonte dos dados

Os dados utilizados neste projeto têm como referência o seguinte repositório:

- [HLTV Scraper - StrandedPond](https://github.com/StrandedPond/hltv_scraper)

O dataset foi desenvolvido por terceiros e será utilizado como fonte de dados para a realização das análises.

## Objetivos do projeto

- Explorar dados estatísticos do Counter-Strike.
- Analisar o desempenho individual dos jogadores.
- Estudar estatísticas e resultados das equipas.
- Identificar padrões e tendências nos dados.
- Desenvolver visualizações estatísticas.
- Explorar possíveis aplicações de Machine Learning.



Projeto em fase inicial de desenvolvimento.
